🎮 Jogo de Palavra Sorteada em Python

Este é um projeto simples desenvolvido em Python para praticar conceitos básicos de programação.

A ideia inicial do projeto é criar um pequeno jogo onde o computador escolhe aleatoriamente uma palavra de uma lista.

🚧 Projeto em desenvolvimento — estou utilizando este projeto para aprender e praticar Python.

📌 Sobre o projeto

Neste primeiro momento, o programa:

Cria uma lista de palavras;
Utiliza a biblioteca random;
Sorteia uma palavra aleatoriamente;
Mostra a palavra sorteada;
Cria uma representação da palavra utilizando caracteres ocultos.

O projeto poderá receber novas funcionalidades conforme meu aprendizado em Python avançar.

🛠️ Tecnologias utilizadas
🐍 Python
📦 Biblioteca random

📚 O que estou praticando

Com este projeto estou começando a praticar conceitos como:

Variáveis;
Listas;
Strings;
Importação de bibliotecas;
random.choice();
len();
Impressão de informações com print();
Lógica de programação.

🎯 Objetivo

O principal objetivo deste projeto é praticar Python e lógica de programação através de um projeto simples e evolutivo.
